## Welcome To The Official Ivy Linux Repository!
You've reached Ivy Linux, a Linux distribution focused on making tasks easy.

## What Is Ivy Linux?
Ivy Linux is an Arch Linux based distribution made to be simple, productive, and clean. It comes with programs for every user, from users who focus on productivity to people who want to practice their hobbies. Ivy Linux comes with software to help people achieve these goals.

## How Do I Install?
Simply download the desktop ISO from the releases tab and burn it to a DVD or USB Flash Drive using software like Balena Etcher. Boot the USB from your computer (If you don't know how to do this, I'd suggest looking up a tutorial). The Ivy Linux live ISO comes with the KDE Plasma 6 desktop and the Calamares Installer. Launch the Calamares Installer from the desktop and fill out the spaces provided. You will need to format partitions of your choice, so back up any data you don't want to lose. Wait for the installer to finish and your new Ivy Linux system is ready for use!

## What Is The Update Schedule?
Minor updates will release every 3-4 weeks with Major updates releasing based on major package releases or multiple features added. 

## What Is The Future of Ivy Linux?
As Ivy Linux continues to bloom, more features and customization is added to make Ivy feel like home. Currently, the latest version of Ivy Linux is 1.0 "Primrose", as it is the first flower to bloom in spring.
